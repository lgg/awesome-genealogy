# Awesome Genealogy [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of genealogy applications, collaborative family trees, archives, transcription tools, visualization tools, data standards, developer resources, and genetic genealogy services.

Genealogy combines historical research, source evaluation, personal data, and long-term preservation. This list focuses on practical tools for building and sharing family trees, working with GEDCOM data, finding and transcribing records, organizing archival research, and developing genealogy software. Treat information about living people and genetic data with particular care, consent, and respect for local law.

## Resource Labels

These labels describe the resources listed below (reviewed October 2026):

`Open Source`: Software released under an open-source license; source availability is separate from pricing.

`Free`: Core listed functionality or access is available without payment.

`Freemium`: A useful free tier or workflow exists, with paid enhancements, extra usage, exports, or services.

`Paid`: Meaningful use generally requires payment, though trials or previews may exist.

Prices, offerings, and availability can change. Self-hosting can incur infrastructure costs, and some archives link to records provided under separate access terms. Absence of an `Open Source` label does **not** prove a resource is closed-source: archives, standards, services, and APIs may not publish software source code. Labels are not attached to the Related Awesome Lists, which index other collections.

## GEDCOM and Data Standards

- [FamilySearch GEDCOM](https://gedcom.io/) - `Free` — Current specification, guides, schemas, sample files, and migration material for the widely used genealogy exchange format.
- [FHISO](https://fhiso.org/) - `Free` — Community organization developing open interoperability standards for family-history information.
- [GEDCOM X](https://github.com/FamilySearch/gedcomx) - `Open Source` `Free` — Extensible data model and serialization formats for exchanging genealogical conclusions, evidence, sources, and records.
- [GEDZIP](https://gedcom.io/specifications/FamilySearchGEDCOMv7.html#the-gedzip-file-format) - `Free` — GEDCOM 7 container format for packaging a tree together with referenced media files.

## Genetic Genealogy

- [DNAGedcom](https://www.dnagedcom.com/) - `Paid` — Utilities for downloading, combining, and analyzing DNA match data from supported testing services.
- [FamilyTreeDNA](https://www.familytreedna.com/) - `Paid` — Commercial genetic-genealogy service offering autosomal, Y-DNA, and mitochondrial DNA tests with matching and project tools.
- [GEDmatch](https://www.gedmatch.com/) - `Freemium` — Third-party autosomal DNA comparison and analysis service for uploaded test data.
- [Genetic Affairs](https://www.geneticaffairs.com/) - `Freemium` — DNA match clustering, tree-building, and research automation tools across supported testing platforms.
- [ISOGG Wiki](https://isogg.org/wiki/) - `Free` — Community reference for genetic genealogy concepts, testing, haplogroups, tools, and ethical considerations.
- [mitoYDNA](https://www.mitoydna.org/) - `Free` — Volunteer-run open database for mitochondrial and Y-DNA sequences, haplogroups, matching, and collaborative research.
- [YFull](https://www.yfull.com/) - `Paid` — Independent Y-DNA and mitochondrial DNA analysis service providing phylogenetic trees, age estimates, matches, and variant interpretation.
